# Authentication

AgentSignalOptimization.com is a public reference site. Reading the ASO framework, score model, manifests, and self-assessment does not require authentication.

## Public Access

- Public homepage: `https://agentsignaloptimization.com/`
- Markdown source: `https://agentsignaloptimization.com/ASO.md`
- LLM guide: `https://agentsignaloptimization.com/llms.txt`
- Agent manifest: `https://agentsignaloptimization.com/agent.json`
- Status manifest: `https://agentsignaloptimization.com/.well-known/status`
- Payments manifest: `https://agentsignaloptimization.com/.well-known/payments`

## Programmatic Access

No API key, OAuth flow, MCP token, or signed agent credential is required for the current public reference materials.

## Commercial Services

ASO audits, reports, monitoring, registry listings, and certification are planned or manual commercial services. Authentication and payment details for those services are not exposed as an autonomous API in this phase.
